# Spotlight Han v1.1.0

這次讓「記得文字，卻不知道檔案在哪裡」更容易解決：圖片與掃描 PDF 可以在本機辨識文字；找到結果後，按空白鍵就能核對內容與 PDF 命中頁。

## 下載與安裝

- Apple Silicon（M 系列）Mac：下載 **Spotlight-Han-1.1.0-macOS-arm64.dmg**，將 App 拖到 Applications；另提供 ZIP、繁體中文安裝說明與 SHA-256 校驗檔。
- 目標最低 macOS 14；已在 Apple Silicon、macOS 26.6.1 驗證，macOS 14／15 與 Intel Mac 尚待實機驗證。目前沒有 Intel 安裝包。
- 更新前先結束 Han，再取代原 App。既有設定與索引沿用；臨時簽章變動可能需要重新授權。

## 新增

- **圖片與掃描 PDF 搜尋**：選擇資料夾後，Apple Vision 在本機背景辨識，繁簡都能搜尋；結果顯示 OCR 命中片段與 PDF 頁碼，不修改或上傳原檔。
- **空白鍵快速預覽**：先以方向鍵或滑鼠選取檔案，再按空白鍵。PDF 跳到命中頁並凸顯文字，可切換命中頁；其他支援格式使用 Quick Look。再次空白鍵或 Esc 返回搜尋，正常輸入空格不受影響。
- **背景 OCR 工作保護**：預設接電執行、使用中降速、閒置加快；低耗電、溫度升高或狀態不明時等待。Logic Pro／Final Cut Pro 開啟或偵測到音訊活動時暫停，可在設定調整。
- **忘記切注音也能找 App**：支援標準大千鍵位，例如 `rnr` 找「計算機」。只用於 App，完整符合才補充。
- **台灣常用詞互搜**：隨身碟／U盤、列印／打印、印表機／打印機、滑鼠／鼠標、軟體／軟件、硬體／硬件。原本精準命中仍在前，不擴張成任意模糊搜尋。
- **更自然的換算**：`3公斤換成磅`、`5公里多少公尺`、`20坪換平方公尺`、`3台斤換公斤`、`37攝氏度`、`115年`。只寫「37度」預設跟隨系統溫標，也能在 Han 固定；台斤與市斤明確區分。
- **重複行程與提醒**：`cal`＋Tab → `每週三晚上七點上課`；`提醒`＋Tab → `每月5號提醒繳房租`。預覽可修改規則，確認後才寫入系統。

## 改善與修正

- 檔案與索引設定整理為「概覽／搜尋範圍／背景辨識／進階」，更容易看懂範圍與處理狀態。
- 精簡沒有內容片段的系統索引結果；每個檔案結果都可查看來源、比對依據與路徑。
- 修正部分搜尋文字對比度、備忘錄／Mail 授權觸發流程，區分拒絕授權與其他系統錯誤。
- **修正 ⌘Space 收起後焦點沒有交回原 App**；Esc 同樣回到原輸入位置。選取結果或開啟設定不會被拉回舊 App。

## 簽章與使用範圍

這是正式 GitHub Release；目前仍採 **ad hoc 臨時簽章，尚未完成 Apple Developer ID 簽章與公證**，下載後可能被 macOS Gatekeeper 阻擋。詳細條件請見[安裝說明](https://github.com/Enoooch0921/Spotlight-Han/blob/v1.1.0/docs/install.zh-Hant.md)。

OCR 僅處理已選且可存取的範圍；iCloud 檔案須已下載到本機，Han 不會為索引自動下載。首次大量 OCR 會增加 CPU／耗電，工作保護是保守避讓，尚未完成真實剪輯／Logic 工作負載的耗電比較；不能保證任何專案都零影響。辨識可能有誤，掃描 PDF 的預覽定位有系統及頁面限制，請核對原文。匯率仍為每日參考值。

自動化檢查使用合成文件及假資料來源，不在私人帳號新增行程／提醒或讀取私人備忘錄；真實系統授權視窗仍依各台 Mac 的狀態而定。
