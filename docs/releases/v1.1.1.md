# Spotlight Han v1.1.1

在「全部」輸入 `-1200+450=`，第一筆會顯示 `-750`，按 Return 即可複製。這次修正了輸入結尾等號後計算結果消失的問題，也支援全形 `＝` 和尾端空白。

- 喚出搜尋浮窗、切換結果與 App 分類時，玻璃背景會沿用同一個表面。分類選取條會滑到選取的位置，按鈕提供按壓回饋。
- 拖曳 App 或重新排列分類時，放開後圖示會收向落點。拖到空白處會回到原位，並修正了空白處可能誤觸第一個分類的問題。
- 長翻譯可以平順展開、收合。新增行程或提醒事項成功後會顯示綠色勾號與建立摘要。動畫會配合 Han 的動畫開關與 macOS「減少動態效果」設定。
- 修正新版 Swift 建置工具打包後，Han 可能找不到行程與提醒事項日期解析元件的問題。

Apple Silicon（M 系列）使用者可下載 **[DMG 安裝檔](https://github.com/Enoooch0921/Spotlight-Han/releases/download/v1.1.1/Spotlight-Han-1.1.1-macOS-arm64.dmg)**。先結束 Han，打開 DMG，將 App 拖到「應用程式」取代舊版。

安裝包採用 ad hoc 簽章，尚待 Apple 公證，macOS 可能會擋下首次開啟。另提供 ZIP 和 SHA-256 校驗檔。[繁體中文安裝說明](https://github.com/Enoooch0921/Spotlight-Han/blob/v1.1.1/docs/install.zh-Hant.md)
