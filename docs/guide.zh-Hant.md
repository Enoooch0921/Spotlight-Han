## 介面與快捷鍵

以 [Apple 的 macOS 27 Spotlight 官方參考](https://support.apple.com/zh-tw/guide/mac-help/mchl4d69efd3/27/mac/27)為設計依據：浮動搜尋膠囊、四個圓形分類入口、輸入後展開的結果面板。macOS 26 以上使用原生 Liquid Glass；較舊系統使用原生模糊材質。透明的 AppKit 容器與四周留白讓系統陰影自然延伸，避免矩形底板及截斷邊緣。提供可關閉的短淡入淡出與面板展開過渡；系統「減少動態效果」啟用時停止高度動畫、保留淡化。切換到其他 App 時立即收起並清除顯示狀態，避免回來要按兩次快捷鍵。詳情在原面板中展開，不使用會在透明視窗四周留下矩形遮罩的彈出頁；語言準備使用獨立的標準視窗。

- 預設 `Control + Option + Space`：開啟／收起搜尋。可在設定錄製自訂組合，需搭配 Command、Control 或 Option；衝突時保留原本快捷鍵。
- `Command + 1 / 2 / 3 / 4`：App／檔案／捷徑／剪貼板。
- `↑ / ↓` 選擇；`Return` 開啟或複製；`Command + R` 在 Finder 顯示。
- `Escape` 收起。選單列可開啟設定與結束 App。

這是獨立產品，不是 Apple Spotlight 的外掛。App 不修改系統 Spotlight；可按「開啟 Spotlight 快捷鍵開關」直接定位到系統勾選框，由使用者關閉原生 `Command + Space` 後，回 App 按「使用 ⌘Space」。也可以隨時改回其他組合、在系統重新啟用 Spotlight。目前以 macOS 26.6.1 驗證；尚未完成 macOS 27 真機逐像素驗收。Logo 是另行製作的放大鏡圖案，未使用 Apple 的 Spotlight 圖檔。Apple 的名稱及商標歸 Apple 所有，專案與 Apple 無關。

## 首次集中選擇檔案範圍

啟動時不會自動探查未選的下載／文件資料夾。按「選擇搜尋資料夾…」，可按住 Command 多選；選擇自己的使用者資料夾時，只把下載、影片、文件加入索引。選擇其他資料夾則索引該資料夾。App 保存並恢復 security-scoped bookmarks，維持已選範圍的存取；資料夾移動／重新命名時會嘗試恢復位置。未選範圍不讀取，也不載入舊快取中的結果。

「移除」停止索引指定範圍；「忘記資料夾」會停止存取、移除保存的書籤及檔名快取。macOS 撤銷權限、磁碟變更、簽章改變或書籤失效時仍可能需要重新選擇，不保證永久免授權。首次檔案選擇、Notes／Calendar 等系統隱私權也仍由使用者確認，並非同一個總開關。

## App 圖示頁與自己的分類

按右側「應用程式」或 ⌘1，直接瀏覽本機 App 圖示，不需先輸入文字；也能切成列表。預設「全部 App」按名稱排列。搜尋仍支援繁簡互搜；搜尋 Wi-Fi 等設定項目時，系統設定入口會另列在上方。

左側內建提供全部、已釘選、最近開啟、系統內建 App，以及工作與學習、影音與設計、通訊與網路、開發工具、系統與工具、遊戲、其他。用途分類由 App 的 `LSApplicationCategoryType` 對應，未提供或無法辨識時放「其他」，不以檔名猜測。「系統內建 App」是獨立入口，依系統 Applications 路徑與 Safari 識別碼判斷，另購的 Apple 專業 App 不會混入。即使手動改分類，仍可在此找到內建 App。每個 App 只有一個用途分類；右鍵「更改分類」可覆寫，亦可還原。點「新增分類」可建立自己的分類（名稱 1–30 字），把 App 圖示或列表項目拖到左側分類即可加入；拖到「已釘選」則釘選。所有分類（包含內建分類）都能上下拖動排序並保存順序；自訂分類右鍵可編輯名稱、選擇22款常用系統圖示或刪除。刪除分類時，App 回到原始用途分類，釘選與最近記錄仍保留。這些操作只整理 Han 內的分類，不搬動、刪除或啟動 App。分類與釘選依 bundle ID 儲存（沒有 ID 時依路徑），移動或升級同一 App 後盡可能沿用。

「建議分類」會在本機比對已安裝 App 的廠商與產品識別碼，預覽 Waves、iZotope、影音製作、Microsoft Office，以及瀏覽器、通訊與會議、影音播放、設計與截圖、雲端與遠端。預覽頁佔滿右側空間，每組可展開完整圖示與 App 名稱；尺寸由面板管理，避免大型清單觸發反覆量測。預設勾選前四組，其他組可自行勾選；確認後建立分類並整理尚未手動分類的 App，不覆寫既有安排，也不傳送 App 清單。這是明確規則的建議分類，未涵蓋的 App 可拖動補上。Waves／iZotope 收錄可啟動的 App 與管理工具，不把 AU／VST 音訊外掛當作獨立 App。

右鍵可釘選常用 App。最近開啟最多20筆，只記錄成功從 Han 開啟的 App，不讀取其他 App 的使用紀錄。這些設定只存本機。App 清單讀取應用程式、系統應用程式與使用者 Applications 資料夾；略過內嵌輔助 App，連結至同一 App 的重複項目只顯示一次。可手動更新清單，新 App 也會在下次進入且距上次超過30秒時重新整理。

點一下圖示即可開啟。搜尋列按↓進入圖示頁，以方向鍵移動、Return 開啟；第一排按↑回搜尋列，左右鍵在輸入框仍保留文字游標操作。⌘R 可在 Finder 顯示目前選取的 App。

面板沿用同一塊系統玻璃材質，以原生視窗過渡維持搜尋列頂部位置；搜尋結果不再依每次筆數變動而反覆伸縮，視窗亦限制在當前螢幕可見範圍。減少動態效果與 Han 動畫開關都會套用到內容切換。這是獨立實作，動畫仍需實際裝置上的手感驗收。

## 省略空格的 App 搜尋與開啟習慣

App 名稱可省略空格或以連字號／底線分隔，例如 `logicpro`、`Logic Pro`、`logic-pro` 都能找到 Logic Pro；`finalcutpro` 也能比對 Final Cut Pro。這個規則只用於 App 名稱與中繼資料，沒有將備忘錄或文件全文的空格任意合併。

內建常見 App 縮寫，一般搜尋與 App 列表共用，大小寫均可。僅比對已安裝的 App；不會為所有名稱任意產生首字母縮寫。完整名稱正好相符的結果仍優先於縮寫，反覆開啟後也會套用搜尋習慣。

| 輸入 | 對應 App |
| --- | --- |
| `fcp`／`fcpx` | Final Cut Pro（含 Creator Studio 名稱） |
| `lpx` | Logic Pro |
| `ps` | Adobe Photoshop |
| `ai` | Adobe Illustrator |
| `ae` | Adobe After Effects |
| `pr` | Adobe Premiere Pro |
| `vscode` | Visual Studio Code |
| `ppt` | Microsoft PowerPoint |

## 拼音、注音與自訂縮寫

中文 App 名稱、檔名與已連接個人資料的標題，可用拼音、拼音首字母、注音或注音首符號搜尋。兩種方式都可使用，與介面語言無關。

| 名稱 | 可輸入 |
| --- | --- |
| 紅果短劇 | `hongguo`、`hong guo`、`hgdj`、`ㄏㄨㄥˊ ㄍㄨㄛˇ`、`ㄏㄍㄉㄐ` |
| 鼎達叔叔 | `dingda`、`ddss`、`ㄉㄧㄥˇ ㄉㄚˊ`、`ㄉㄉㄕㄕ` |
| Terminal／終端機 | `zhongduanji`、`zdj`、`ㄓㄉㄐ` |

名稱的轉寫鍵在載入或建立索引時產生，查詢時比對；不是每次輸入都重新轉寫全文。舊版檔名快取載入時會補上轉寫鍵。只針對名稱／標題，不轉寫 Word 或備忘錄的整篇內文。拼音接受大小寫、音調及聲調數字；單一英文字母不啟用首字母搜尋。注音使用注音符號，聲調可省略。多音字採系統轉寫的讀法，可用自訂縮寫加入其他讀法。

**自訂縮寫：**先找到 App、檔案或個人資料結果，按右鍵 →「自訂搜尋縮寫…」。例如為剪輯軟體加入「我的剪片」。每個項目最多8個縮寫，以逗號分隔；每項最多32字。大小寫及繁簡互通，縮寫須完整輸入。再次編輯並留空儲存即可移除。

自訂縮寫與對應項目的識別資料（App bundle ID、檔案路徑或來源識別碼）只儲存在本機設定，不上傳。它與下方的匿名化學習紀錄分開；關閉習慣學習不會移除自訂縮寫。最多2,000個自訂項目。縮寫不會繞過搜尋範圍、檔案類型或資料來源授權，也不會找回未載入或已消失的資料；計算器和新增事項指令仍優先。

## 本機搜尋習慣

「搜尋習慣」預設開啟。成功開啟 App／檔案、成功切到備忘錄、顯示聯絡人／行程／提醒詳情、開啟郵件或成功執行已確認的捷徑後，才記錄該搜尋詞的選擇；僅選取、滑過、開啟失敗、計算器／翻譯／剪貼板等不學習。相同搜尋詞的重複選擇優先；不同詞也會小幅參考常用結果與類型。單次誤開不會直接蓋掉明確的完整名稱符合。分數隨未使用時間減弱（90天半衰期），365天未用移除，最多2,000組。

這項學習從 0.8.1 更新後開始累積；舊版只有最近開啟 App 清單，無法回溯更新前搜尋各個詞的開啟選擇。

App、備忘錄與檔案結果採共同的顯示與鍵盤順序，學到的 App 或檔案能排到備忘錄前面。計算器、匯率、翻譯與指令仍保持獨立的優先位置。行事曆專屬頁仍保留日期排序，全部結果中的行程相對日期順序也不打亂。空白查詢的 App 分類不因習慣重新洗牌。

只保存每台安裝的加鹽 SHA256 識別碼、類型、次數與時間；不保存原始搜尋文字、檔案路徑、標題或內容、不上傳。設定可停止記錄與套用，亦可清除既有紀錄與更換雜湊鹽值。重新啟動後沿用本機學習；App 優先依 bundle ID 識別，檔案依路徑、個人資料依來源識別碼，因此檔案搬移或來源識別碼改變後可能需重新學習。

## 更新提醒與測試版 DMG

選單列與「關於」提供 GitHub 專案原始碼入口，「關於」亦可直接前往 Issues 回報問題。

選單列「檢查更新…」或設定「軟體更新」可手動檢查。預設每天最多自動檢查一次，檢查時間與公開版本快取會保存，重開 App 仍沿用間隔；失敗則退避至少一小時。0.x 開發預覽預設包含測試版，也可關閉，或完全關閉自動檢查。

有比目前版本更新、且提供此 Mac 架構 DMG 的公開版本時，搜尋面板與選單列會顯示提醒，設定中可看上次檢查時間、版本內容及直接下載 DMG。可按「稍後」在本次執行中收起橫幅。只連線 GitHub 公開 Releases API，不傳送搜尋文字、檔名或已安裝 App 清單；不自動安裝、不要求額外通知權限。離線／服務不可用會清楚顯示檢查失敗，已知的新版本仍保留。

## 一次集中設定，之後自動連接

在設定中按 **「一次設定所有資料來源」**，會依序連接備忘錄、聯絡人、行事曆、提醒事項、郵件、捷徑與系統時鐘。成功啟用的來源會記住，之後啟動會自動讀取，不需要每次逐個連接。

已連接後按 **「全部重新讀取」**，即可一次安排全部已啟用／曾連接的系統 App 來源更新，不必逐個按；不受背景更新開關或更新間隔限制，也不會彈出授權視窗。每個來源保留獨立狀態，最後顯示完成與需注意的數量；某個來源缺少權限時會略過，繼續其餘來源。首次連接則使用「一次設定所有資料來源」。

只有系統明確拒絕、限制或僅允許新增時，才顯示「開啟隱私權設定」；已授權及尚未決定都不顯示。從系統設定返回 Han 後會重新檢查待授權來源，已允許的來源會自動重新讀取。

首次連接與授權共用同一個佇列，同一時間只處理一個授權視窗。已授權的行事曆與提醒事項使用獨立背景讀取，不被備忘錄／郵件阻擋。變更通知會保留到可更新時；讀取途中再有變動，也會接續更新，不會被此次完成狀態蓋掉。啟動時若發現權限不足，會提示手動重新連接，避免自動重複跳出授權視窗。聯絡人、行事曆與提醒事項的授權請求在主執行緒發起，資料讀取則在背景處理；等待系統授權最多兩分鐘，逾時會結束等待並顯示原因。

設定視窗開啟期間，Han 以一般前景 App 呈現系統授權，因此 Dock 暫時會有 Han 圖示；關閉設定且沒有授權請求時恢復選單列模式。Contacts 授權物件持續保留；EventKit 授權、搜尋、目的地清單與新增共用同一個長存服務。EventKit 物件留在主 actor，純文字搜尋資料在背景處理。針對部分 Mac 在授權成功後仍回傳 notDetermined 的狀況，服務銜接當次成功回呼，不將尚未更新的查詢結果誤判成失敗；這份證據只留在本次執行的記憶體，明確的拒絕、限制、僅寫入或已觀測完整授權後的重設都會使它失效。本次聯絡人與提醒事項的授權按鈕均已由使用者確認可點擊。

備忘錄首次讀取可能需要時間，尤其是資料多、iCloud 正在同步或 Notes 忙碌時。Han 先取得最多 2,000 則固定識別碼，每批最多 50 則、約 12 秒後讓出，單次程序最多等候 30 秒；批次結束後自動接續剩餘識別碼，不會因整批超過 90 秒而停止，也不會每次從第一則重來。畫面顯示已檢查／總數，已讀內容可先搜尋；刷新期間保留先前搜尋副本，完成後才替換。單則逾時會先移至隊尾，兩次仍逾時則略過並明示讀取不完整；受保護筆記依範圍排除，另列數量。接續進度只留在此次執行的記憶體。可按 **「停止連接」** 清除剩餘佇列並停止備忘錄／郵件的讀取程序，已載入內容仍可搜尋。這個按鈕不能代替使用者選擇或關閉 macOS 的授權對話框。

macOS 的 Contacts、Calendars、Automation 是不同權限；系統仍可能分別請你確認。完整磁碟存取也不能取代這些權限，App 沒有一個可略過它們的總開關。[Apple 權限說明](https://support.apple.com/en-au/guide/mac-help/mchl211c911f/mac)

目前本機建置預設是 ad hoc 簽章，重新編譯後程式的代碼身份可能改變，系統可能重新詢問權限。正式版本應使用穩定的 Apple Development／Developer ID 簽章；可透過 `CODE_SIGN_IDENTITY` 指定已有的簽章身份。腳本不會建立憑證、改寫系統授權資料庫或關閉系統保護。

## 翻譯與每日參考匯率

在設定的「翻譯與貨幣換算」選擇來源及目標語言；來源預設自動偵測，目標預設繁體中文。可選項目由 Apple Translation 回報的支援語言產生；實際語言配對仍可能不支援。改目標後會重新檢查模型與更新翻譯，舊配對的結果不會套用到新目標。中文查詢可翻成英文等其他語言；同語言不重複翻譯。語言選單不代表已下載模型。

原查詢及 App／檔案結果保持原樣，不會自動改用譯文搜尋。翻譯不搶走已選結果的 Return 動作。缺少語言時顯示「準備本機翻譯語言」，選取後按 Return 或按設定的「準備所選翻譯語言…」，開啟獨立視窗。按「查看系統語言下載」進入 macOS，回來後每 3 秒檢查所選配對是否已安裝，並顯示等待時間與上次檢查時間。**Apple 公開 API 沒有提供下載百分比或剩餘容量**；等待指示器代表持續檢查，不能當成下載進度百分比。下載與完成狀態由 macOS 管理。一般搜尋不會自動跳出下載對話框；macOS 26 以上只使用已安裝語言的 session，26.4 以上偏好 low-latency 模型。

介面語言在「一般」另外選擇，會保存並更新 Han 的介面文字；macOS 自己的選單、授權視窗及系統設定仍由系統語言控制。自然語言行程／提醒／鬧鐘指令目前仍以中文語法為主。

登入時啟動使用系統 SMAppService，可在「一般」開關；若 macOS 顯示待批准，按「開啟系統登入項目」。請把 App 放在固定位置，再啟用。註冊失敗會顯示錯誤及實際狀態。系統登入啟動時會留在背景，手動開啟才顯示搜尋框。

設定快捷鍵時會檢查系統使用中的組合；⌘Space 若仍被 Spotlight 使用，會明確提示並保留原快捷鍵。可直接前往系統 Spotlight 快捷鍵頁面；回到 Han 後會再檢查。一般快速搜尋直接顯示結果；查詢超過150毫秒時，輸入框才顯示小型系統忙碌指示器，底部顯示實際搜尋階段。沒有可計算的總量時不顯示跑滿式橫條。備忘錄分批載入、行事曆更新及檔名索引完成，只會合併刷新目前結果，不重啟可見搜尋、不清除詳情或搶走仍有效的選取項目，也不會因私人來源更新而重新呼叫系統全文索引。資料來源的進度與狀態獨立顯示。

貨幣辨識支援前置／後置 NT、NT$、TB、台幣、TWD，以及 RMB、人民幣、CNY 等寫法；例如 `3000台幣=rmb`、`nt3000 = rmb`、`3000nt = rmb`、`100 USD to TWD`。也支援 `3000tb=rmb` 或 `3000tb rmb`，`TB` 在貨幣查詢中代表台幣。在設定勾選多個預設目標後，輸入 `3000tb` 或 `3000台幣` 就會同時顯示；預設為 CNY、USD、JPY。明寫目標會優先於預設，也可輸入 `3000tb=rmb,usd,jpy` 或 `3000tb rmb usd`。支援以國名和常用簡稱指定貨幣：`3000NT=馬來西亞`、`3000NT 马来`、`3000NT=Malaysia` 都是 MYR；`3000NT=New Zealand` 是 NZD，亦可寫 `3000NT=馬來, United States, South Korea`。國名由本機系統語系資料對應目前支援的幣別，另補常見別名；英文大小寫和多餘空格均可辨識。歐盟／歐洲等涉及多個幣別的區域不自動猜測。結果顯示貨幣名稱與代碼。多個目標共用同一份匯率表，不額外對每個幣別連網。`1 TB to GB` 這類容量換算仍交給單位換算。

它採用 [ExchangeRate-API 免費公開端點](https://www.exchangerate-api.com/docs/free)，**每日更新，非即時／盤中行情**。畫面附上來源連結、匯率資料時間與「每日更新」，也會標示離線時使用的過期快取（最多七天）。這是參考中間價，並非銀行買入／賣出或實際成交價。

只請求固定的公開 USD 匯率表，在本機換算；不傳送輸入金額、完整查詢、檔名、文件或私人資料。共用匯率快取並合併同時請求，失敗後會退避，避免每輸入一個字就連網。開源程式碼不包含即時匯率的付費帳號或 API Key。

## 資料來源狀態與行事曆排序

設定中的每個私人資料來源，以及檔名／資料夾內容索引，都有圖示、文字及顏色狀態：綠色「已更新」、藍色讀取中、橘色資料已舊／部分資料／待授權，以及紅色「讀取失敗」。只有完整讀取成功才更新「上次完整更新」時間；重試失敗或停止時會保留舊時間，並明示目前仍顯示舊／部分副本，或完全沒有可用資料。

超過 15 分鐘未完整更新會標示資料已舊，畫面每 30 秒檢查一次；收到 EventKit 的行事曆／提醒事項變更通知，也會立即將已載入副本標為待更新。背景自動更新預設開啟，Han 執行期間每分鐘檢查排程：行事曆／提醒事項每 5 分鐘及變更通知後（合併 2 秒內通知）重讀；其他已啟用來源、已選檔名範圍與當次全文索引每 15 分鐘更新。讀取失敗／部分讀取／停止後至少等待 15 分鐘再背景重試。設定可關閉自動更新。背景只排入 `allowPrompt: false` 的共用佇列，執行前再檢查授權；權限失效會暫停並顯示需要重新連接，絕不在背景要求新授權。這是定期與變更驅動的快取更新，並非跨裝置即時同步的保證。搜尋面板會顯示需注意的來源及重新讀取按鈕，設定可檢視全部來源。

行事曆搜尋使用實際起訖日期排序，不再沿用系統回傳順序。預設先排進行中及未來行程（開始時間由近到遠），過去行程再由近到遠；有相同日期時以穩定識別碼排序，缺少日期的項目最後。結果顯示起訖日期、所屬行事曆與「即將到來／進行中／已過去」。在行事曆分類及含行程的全部結果中，可切換「即將到來優先／日期由新到舊／日期由舊到新」，並保存選擇。搜尋仍限定已載入的前後各一年資料。

## 自然語言快速新增與預設行事曆

1. 輸入 `cal`、`calendar`、`行事曆`或`行程`後按 Tab，進入新增行程；輸入`提醒`、`提醒事項`、`rem`或`reminder`後按 Tab，進入新增提醒。
2. 輸入「明天下午三點到四點和鼎達叔叔開會」、「下下週一上午10點開會30分鐘」或「30分鐘後喝水」。英文也可用 `tomorrow at 3pm meeting for 30 minutes`。
3. 畫面先顯示解析摘要。Return／「預覽與調整」進入確認預覽，可改標題、日期、開始／結束時間、全天與行程通知。
4. 「確認建立」或 ⌘Return 才會寫入。再次按一般 Return 不會直接新增。取消會清除草稿；相對時間以畫面預覽的日期為準，等待確認不會偷偷延後。

在 Han 設定的「行程、提醒與鬧鐘指令」選擇 **Han 預設行事曆**。初次可按「讀取可寫入的行事曆…」，授權後只取得清單，不會因此載入所有行程內容。預設可跟隨系統，或固定到一個可寫入的行事曆；只改 Han，不改系統偏好。

確認預覽的「本次加入行事曆」可以覆寫這一筆的目的地，不改預設。相同名稱會加上帳號來源協助辨識。原本選擇被刪除、帳號移除或變成唯讀時會要求重新選擇，絕不默默改存其他行事曆。提醒事項目前使用系統預設提醒清單。

只填日期會建立全天行程／不指定通知時分的提醒。提醒事項的日期通知依系統設定；指定時間會附上通知。行程未寫時長時預設 1 小時；可寫 30 分鐘、1 小時30分鐘，或明確的結束時間，也可用「提前10分鐘提醒」。

日期解析採固定版本 Chrono 2.10.3 與 Han 規則，在 JavaScriptCore 本機執行，無網路、帳號、API Key、Python 或 Node.js 執行期需求。補強涵蓋以週一為起點的「下週／下下週」與下午時間區間。解析器並非任意自然語言模型；多個獨立時間、模糊時段、重複規則或已過去的時間會要求改寫。這版先支援單次事項，重複規則請到系統 App 編輯。

自動化檢查涵蓋完整的預覽／確認流程與 EventKit 物件欄位，使用假寫入器，**不會在私人帳號建立測試行程或提醒**。

## 系統時鐘：只需加入一次

1. 在 App 的設定按 **「連接系統時鐘」**。
2. 在 Apple 捷徑視窗檢視並按 **「加入捷徑」**。不用編輯動作或填寫時間參數。
3. 回到 App 會自動檢查連接；也可手動按「檢查連接」。之後直接輸入 `設定30分鐘後的鬧鐘`，預覽後按 Return。

內附的 `Spotlight-Han-System-Clock` 只把本機 JSON 中的時間與標籤交給 Apple 時鐘的「加入鬧鐘」動作，最後回傳完成標記。App 使用 [Apple 支援的 shortcuts 命令列介面](https://support.apple.com/en-gb/guide/shortcuts-mac/apd455c82f02/mac)，不需要使用者手動製作捷徑。捷徑可檢閱原始碼於 [SystemClock.plist](../Assets/Shortcuts/SystemClock.plist)；發行檔已簽署。App 會建立並清除本機暫存 JSON，不使用剪貼板，不上傳鬧鐘資料。首次加入的系統操作無法由 App 靜默代替；系統仍可能顯示自己的執行確認。

鬧鐘由 Apple 時鐘響鈴及管理，Spotlight Han 不維護另一份鬧鐘清單。超出下一次指定時分的未來日期會拒絕建立，請改用提醒事項，避免系統鬧鐘提早響鈴。秒數向上取整到分鐘，實際時間在預覽顯示；相對時間在按 Return 時起算。此版本尚未接入系統「計時器」，不把倒數指令悄悄改成鬧鐘。

已在 macOS 26.6.1 實測由橋接捷徑建立有名稱的系統鬧鐘、核對時間與名稱，並清除測試鬧鐘。若捷徑執行失敗或未收到完成回覆，App 會要求先開啟時鐘核對，避免盲目重試。行事曆／提醒事項的寫入使用 EventKit，需你授權；私人帳號的實際寫入未納入自動化測試。

## 建置

需要 macOS、Swift 5.9 以上，以及含 macOS 26 SDK 的 Xcode／Command Line Tools。執行最低 macOS 14；目前本機驗證為 Apple Silicon。

```sh
git clone https://github.com/Enoooch0921/Spotlight-Han.git
cd Spotlight-Han
./script/build_and_run.sh
```

腳本建立 `outputs/Spotlight Han.app` 並以本機簽章啟動。`--build-only` 只建置，不啟動。沒有第三方套件依賴；發行給其他 Mac 的 Developer ID 簽章與公證尚未設定。

公開預覽安裝包與發佈狀態請見 [Releases](https://github.com/Enoooch0921/Spotlight-Han/releases)。0.8.2 提供 Apple Silicon DMG 拖曳安裝與 ZIP 包，使用 ad hoc 簽章，下載後可能被 Gatekeeper 阻擋；詳見[安裝說明](install.zh-Hant.md)。

```sh
./script/package_release.sh
```

打包腳本使用 Release 組態，建立獨立暫存 App、驗證簽章，將 ZIP、安裝說明與 SHA-256 校驗檔輸出至 `outputs/releases/`。不會重啟或覆蓋正在使用的本機 App。`HANSEARCH_BUILD_CONFIGURATION` 與 `HANSEARCH_APP_BUNDLE` 可供建置腳本指定組態及輸出路徑。腳本不會自動公證；即使指定 Developer ID 身分，仍須另外完成 hardened runtime、相關 entitlement 檢查與公證。

```sh
swift run HanSearchChecks
./script/check_localizations.sh
swift run HanSearchChecks --benchmark
python3 script/verify_clock_shortcut.py
python3 script/check_notes_stream.py
mkdir -p work
swiftc -parse-as-library Sources/HanSearch/Services/FileAccessBookmarks.swift script/check_folder_bookmarks.swift -o work/BookmarkChecks
work/BookmarkChecks
```

使用獨立檢查程式，能在沒有 XCTest 的 Command Line Tools 環境執行。涵蓋真實 DOCX 擷取、檔名索引、繁簡比對、算式安全、單位換算與查詢跳脫。`--benchmark` 使用本機現有檔名快取，僅印數量與比對時間，不印私人路徑或檔名。

目前共 30 組核心檢查，包含來源佇列排隊／去重／取消、系統回呼逾時／取消／延遲回覆，以及讀取程序的串流與強制逾時。備忘錄另以假的 Notes 橋接測試實際使用的 JXA 腳本，驗證分批輸出、Unicode、受保護項目跳過與文字容量上限；不會讀取私人備忘錄，也不能取代真實系統授權視窗的互動驗收。

## 搜尋範圍與更新

已選範圍的檔名清單在啟動時掃描，叫出面板時如距上次更新超過 30 秒會重新掃描；新檔案可手動按更新。**不是即時檔案監看器**。隱藏檔、套件內部，以及 `node_modules`、`Pods`、`DerivedData`、`venv`、`__pycache__` 的內部預設不掃描；最多 500,000 筆。無權讀取與超限會顯示狀態。

「全部」預設會補上全機已索引文件的內文結果；不必選擇資料夾或切換頁面。App／檔名等快速結果先顯示，稍後合併內文結果並保留已選取項目。同一路徑去重，保留直接擷取的原文字摘要；系統索引結果標示「文件・系統索引」，不保證有摘要。新查詢會取消舊查詢，來源的安靜刷新沿用同詞內文結果，不反覆啟動全機查詢或播放搜尋進度。

全機部分依賴 macOS 的 Spotlight 索引：沒有索引、被排除、未下載、加密或無權限的文件可能缺席。它不是每次輸入都讀遍硬碟。支援索引中的 Word、PDF、PPT／PPTX、RTF、ODT、HTML 和常見純文字。關掉原生 Spotlight 快捷鍵不會關掉索引。「全部」即使加入補強資料夾，仍會查詢全機；專屬「文件內容」頁有指定資料夾時維持該範圍。設定可關閉「全部」的全機文件搜尋。系統文件查詢沿用原生 Spotlight 分詞，也可能依檔名或可搜尋中繼資料命中，不限定只有內文。

指定資料夾的直接內文索引只留在記憶體，結束後需重新加入；修改文件後按重新讀取。支援 DOC／DOCX、文字層 PDF、PPTX／PPSX／POTX／PPTM 等。PPTX 讀取投影片、講者備忘稿及圖表／SmartArt 文字，不啟動 PowerPoint、不執行巨集、不解壓檔案到磁碟。舊版 PPT／PPS／POT 依系統索引提供文字，無法直接取得文字時會列入未完成原因，仍可在「全部」透過系統索引搜尋。單檔 20 MB、文字總量 32 MB、最多 10,000 份文件；簡報 XML 另有 8 MB／2,000 個文字部件上限。掃描 PDF、照片沒有 OCR；非 UTF-8 純文字可能無法讀取。

讀取統計分開列出已檢查檔案、可搜尋內文、未完成與未支援格式。「查看未完成的檔案與原因」會顯示原因分類、檔名及所在路徑，右鍵可在 Finder 顯示；明細最多列200份，分類數量仍包含全部。原因包括單檔過大、內文總量達限、雲端未下載、PDF 空白／圖片或密碼保護、舊 PPT 需要系統索引，以及格式／權限／讀取錯誤。這些明細只留在本機記憶體，不會自動上傳。

## 隱私與儲存

- 沒有自建伺服器、分析追蹤或查詢自動上傳。貨幣換算會按需下載公開匯率表；首次翻譯會由 Apple 下載語言模型。
- 檔名及其所在路徑快取於使用者的 `Library/Caches/local.hansearch.mac/Filenames-v1.json`。它包含私人檔名，不應分享。
- 已選資料夾的存取書籤、索引範圍、快捷鍵與啟用的資料來源記錄於本機偏好設定，不納入 Git。
- 文件內文與已連接的私人資料搜尋副本只留在記憶體；不存進檔名快取。行程／提醒只有在按「確認建立」或 ⌘Return 後才寫入；時鐘鬧鐘仍按 Return 建立。
- 剪貼板預設關閉。會略過隱藏／暫存標記及常見密碼管理器，但其他 App 沒標示的敏感文字仍可能被記錄。關閉即清除記錄。
- 備忘錄不會解鎖受密碼保護的筆記。來源移除會清掉記憶體副本；撤銷系統授權請到系統設定。
- `work/`、`outputs/`、建置產物和本機索引不納入 Git。
